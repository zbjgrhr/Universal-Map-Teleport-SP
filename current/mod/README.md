# Map Teleport – Right-Click Rescue

## 中文

面向 Project Zomboid B42.21 单人及多人游戏，在世界地图右键菜单加入独立的 **Teleport Here**。

- 与地图、导航/GPS、路线、目的地、标记、传送及作弊菜单等模组的右键选项同时显示、分别选择。
- **Teleport Here** 传送人物、背包或手中携带的动物，以及绳索牵引的动物；坐车时也可直接传人，人物离开座位后传送，车辆及其他乘客留在原地。
- 多人游戏中所有玩家均可使用，不需要管理员批准。
- 本基础版不需要 ZombieBuddy。

### 备用键盘快捷键

进入 **Options → Key Bindings → Universal Map Teleport**，为 `UMTSP: Teleport Here (World Map)` 设置键盘按键。打开世界地图，将鼠标指向目的地后按键。快捷键默认未绑定。

多人游戏需要服务器和客户端安装相同版本。

## English

Adds an independent **Teleport Here** action to the Project Zomboid B42.21 world-map right-click menu in single-player and multiplayer.

- Map, navigation/GPS, route, destination, marker, teleport and cheat-menu actions from other mods can remain visible and separately selectable.
- **Teleport Here** moves the character, inventory or hand-carried animals, and rope-led animals. Also works while seated: your character leaves the seat and teleports; the vehicle and other passengers stay behind.
- Every multiplayer player can use it without administrator approval.
- This base edition does not require ZombieBuddy.

### Backup keyboard shortcut

Open **Options → Key Bindings → Universal Map Teleport** and bind `UMTSP: Teleport Here (World Map)`. Open the world map, point at the destination and press the assigned key. It is unbound by default.

Multiplayer servers and clients need the same version.
