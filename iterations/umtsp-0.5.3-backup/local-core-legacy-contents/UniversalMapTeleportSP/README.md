# Universal Map Teleport — Map Right-Click Rescue（B42.21）

这是针对《Project Zomboid》Build 42.21 **世界地图右键菜单冲突**的单机与多人传送模组。导航、路线、GPS、地图标注、作弊或其他传送模组共用右键菜单时，它在已有菜单项旁补入自己的 **Teleport Here**。同一菜单可同时显示多个模组的选项，玩家分别选择执行。AutoDrive 的 **Add Destination** 是其中一个例子，本模组不依赖 AutoDrive。多人模式下所有玩家都可直接使用，无需管理员权限或人工批准；服务器自动执行传送。Mod ID 仍为 `UniversalMapTeleportSP`，以保持旧存档和 Workshop 项目兼容。

本模组通过兼容性包装补入菜单项，不删除其他模组的回调。游戏开始后若有模组替换右键回调，本模组会在下次打开世界地图时重新接入；如果地图打开后仍被替换，可使用备用键盘快捷键。不能保证与任意第三方地图 UI 模组百分之百兼容，也没有逐一测试 Workshop 上的所有同类模组。

## 安装

1. Workshop 安装：订阅后，在单机存档或多人服务器的模组列表中启用。多人游戏需要服务器和客户端都安装同一版本。手动安装：把本上传包内的 `Contents\mods\UniversalMapTeleportSP` 复制到 `C:\Users\<你的用户名>\Zomboid\mods\`。
2. 进入游戏前退出并重新启动客户端。旧存档可中途启用；首次测试前建议备份存档。
3. 进入存档，按 M 打开世界地图，右键有效地图位置，点击 **Teleport Here**。
4. 备用入口是**键盘快捷键**：在 **Options → Key Bindings → Universal Map Teleport** 为 `UMTSP: Teleport Here (World Map)` 指定一个空闲按键。默认不绑定。打开世界地图，把鼠标指向目标位置后按所设按键。按键项的内部名称保持不变，旧玩家的绑定仍可沿用。

支持单机、联机主机和专用服务器；多人功能需要实机验收。游戏版本低于 42.21 不支持。

## 工作方式

- 已核实 B42.21 原版 `ISWorldMap` 用 `mapAPI:uiToWorldX/Y` 转换地图指针，原版 `onTeleport` 的单机分支调用 `IsoPlayer:teleportTo`。
- 已核实当前安装的 DerpyAutodrive 42.19 把 `ISWorldMap:onRightMouseUp` 包装在自己的回调中，随后会根据返回值调用 `ISContextMenu.get`；后者会清空菜单。MapTeleport 旧模组则直接替换同一个回调。
- 本模组在 `OnGameStart` 包装当时已安装的地图右键回调，让原回调先创建菜单，再把自己的选项插在顶部。每次重新打开世界地图时也会检查回调是否被替换。它不清空已有菜单，也不使用每帧重挂钩。其他模组已生成的路线、目的地、标记和传送等选项可与本模组选项同时出现、分别点击；其他模组自行清除的选项无法由本模组重建。
- 若其他模组在地图已经打开之后彻底替换右键回调，主入口仍可能消失。此时使用备用键盘快捷键；该入口不经过右键回调。
- 多人模式通过内部命令通知服务器；服务器核验玩家、坐标与乘车状态，自动移动发起操作的玩家。落点调整及失败返回同样由服务器执行；没有管理员权限或人工批准要求。

## 传送安全与限制

- 地图坐标必须位于游戏 MetaGrid 有效区块。
- 已加载地点：在所选地面格及半径 3 格内寻找有地板、非水面、可站立的 Z=0 地格；找不到则拒绝传送。
- 远距离地点通常尚未加载。此时先调用 B42.21 原版使用的 `IsoPlayer:teleportTo`，等待游戏载入目的地区块，再检查所选地格及附近半径 3 格的地面；若所选格不可站立，则移动到附近安全格。找不到安全格或等待超过 600 tick 时，尝试返回原点。这个检查发生在移动之后，因此远距离传送仍有短暂的未验证落点风险；请先在备份存档中测试。
- 世界地图不提供楼层信息，本模组只选 Z=0；它不保证抵达地图上所见建筑的上层。目前乘车时拒绝传送。车辆与乘客跨区块传送还涉及物理状态及多人同步，不能用角色传送接口直接实现。
- 菜单和快捷键都只在世界地图上使用。传送会关闭地图。
- 多人模式需服务器安装本模组。服务器或客户端版本不一致可能导致传送请求无响应；请核对双方版本和日志。

## 兼容范围

- 设计目标：世界地图右键菜单中的导航/GPS、路线规划、目的地、航点/标记、地图传送、作弊/调试和 NPC 地图标记等选项。多个选项可在同一菜单中并列、分别点击；前提是相关模组把选项保留在最终菜单中。
- 已在模拟环境核验 AutoDrive 先后加载、保留 `Add Destination`；已阅读本机 Project Remnants、MapTeleport、Cheat Menu Rebuild 的相关代码。后几者以及其他 Workshop 模组尚未完成游戏内组合测试，不能列为已确认兼容。
- ZombieBuddy 本体是 Java 模组加载框架，不直接提供世界地图右键选项，预计没有直接菜单冲突；与 ZombieBuddy 及其加载的具体 Java 模组共用尚未实测。

## 地图右键模组共存测试

请在同一测试存档依次测试：只启用本模组；与所用的导航、路线、GPS、标注或传送模组一起启用；交换加载顺序；分别点击 `Teleport Here` 和其他模组的菜单项，确认各自回调都能执行。AutoDrive 可用 `Add Destination` 作例子。不要把“菜单显示”当作“回调可执行”的证明。

建议额外测试不同缩放、拖动后的目标坐标，已加载空地、墙边、水边、远距离跨城落点和加载失败后的返回、旧存档启停、重复打开地图与连续传送。失败后核对角色位置及 `C:\Users\<你的用户名>\Zomboid\console.txt`。

## 日志与配置

日志前缀：`[UniversalMapTeleportSP]`。默认只记录加载、注册、传送结果与错误。在 `42\media\lua\client\UMTSP_Config.lua` 设 `debug = true` 可记录地图右键和菜单插入细节；改动后重启游戏。也可在那里调整安全地格搜索半径与传送到达超时。
